# พอร์ตโฟลิโอวิศวกรรม — คู่มือใช้งาน

เว็บไซต์นี้เป็นพอร์ตโฟลิโอ 12 หน้า **แยกไฟล์ต่อหน้า** ธีมขาว-ดำแบบ Apple.com
แต่ละหน้าเป็นไฟล์ .html ของตัวเอง เชื่อมกันด้วยเมนู/ปุ่มเลื่อนหน้าถัดไป-ก่อนหน้า

## โครงสร้างไฟล์
```
portfolio-site/
├── index.html         ← 01 ปกหน้า
├── toc.html           ← 02 สารบัญ
├── profile.html       ← 03 ประวัติส่วนตัว
├── education.html      ← 04 ประวัติการศึกษา
├── skills.html        ← 05 ความสามารถ/ทักษะ
├── activities.html     ← 06 กิจกรรมและประสบการณ์
├── project-1.html      ← 07 ผลงานที่ 1
├── project-2.html      ← 08 ผลงานที่ 2
├── project-3.html      ← 09 ผลงานที่ 3
├── project-4.html      ← 10 ผลงานที่ 4
├── awards.html         ← 11 รางวัลและเกียรติบัตร
├── contact.html        ← 12 ปกหลัง/ติดต่อ
├── style.css           ← ดีไซน์ทั้งหมด (ใช้ร่วมกันทุกหน้า)
├── app.js              ← เมนู, ปุ่มเลื่อนหน้า, แอนิเมชัน (ใช้ร่วมกันทุกหน้า)
└── images/             ← ใส่รูปจริงของคุณที่นี่
```

ทุกหน้าโหลด `style.css` และ `app.js` ไฟล์เดียวกัน — แก้ดีไซน์หรือเมนูที่ไฟล์เดียว มีผลทุกหน้าทันที
ถ้าเพิ่ม/ลบ/สลับลำดับหน้า ให้แก้ลิสต์ `PAGES` ที่ต้นไฟล์ `app.js` ด้วย (เมนูและปุ่มก่อนหน้า/ถัดไปจะอัปเดตตาม)

## ขั้นตอนที่ 1: แก้ไขเนื้อหาให้เป็นข้อมูลจริง
เปิดไฟล์แต่ละหน้า แล้วค้นหาคำว่า **[แก้ไข]** และข้อความในวงเล็บเหลี่ยม `[ ]`
ทุกจุดคือที่ที่ต้องใส่ข้อมูลจริงของคุณ เช่น ชื่อ, โรงเรียน, GPA, รายละเอียดผลงาน ฯลฯ

## ขั้นตอนที่ 2: ใส่รูปภาพ
1. นำรูปของคุณ (โปรไฟล์ 1 รูป + ผลงาน 4 รูป) ไปวางในโฟลเดอร์ `images/`
   ตั้งชื่อไฟล์เป็น `profile.jpg`, `project1.jpg`, `project2.jpg`, `project3.jpg`, `project4.jpg`
2. ในไฟล์ .html ที่เกี่ยวข้อง หาบล็อกที่เขียนว่า `photo-placeholder` แล้วแทนที่ด้วยแท็ก `<img>`
   ตัวอย่าง — จากเดิม:
   ```html
   <div class="photo-placeholder">
     <span>ใส่รูปโปรไฟล์</span><small>images/profile.jpg</small>
   </div>
   ```
   แก้เป็น:
   ```html
   <img src="images/profile.jpg" alt="รูปโปรไฟล์">
   ```
   (แท็ก `<img>` จะเข้ากรอบพอดีอัตโนมัติ เพราะ container `.photo-frame` จัดการให้แล้ว)

## ขั้นตอนที่ 3: อัปโหลดขึ้น GitHub Pages (ฟรี)

### ก. สร้าง Repository
1. ไปที่ https://github.com แล้วล็อกอิน (ถ้ายังไม่มีบัญชี ให้สมัครฟรี)
2. กดปุ่ม **New** (สร้าง repository ใหม่)
3. ตั้งชื่อ repository เช่น `my-portfolio`
4. เลือก **Public** แล้วกด **Create repository**

### ข. อัปโหลดไฟล์
1. ในหน้า repository ที่สร้างใหม่ กด **Add file → Upload files**
2. ลากไฟล์ .html ทั้งหมด, `style.css`, `app.js` และโฟลเดอร์ `images` (พร้อมรูปข้างใน) เข้าไป
   **สำคัญ:** ต้องอัปทุกไฟล์เข้า root ของ repository ระดับเดียวกัน (ห้ามใส่ในโฟลเดอร์ย่อย) ยกเว้นโฟลเดอร์ `images`
3. เลื่อนลงมากด **Commit changes**

### ค. เปิดใช้งาน GitHub Pages
1. ไปที่แท็บ **Settings** ของ repository
2. เมนูซ้ายเลือก **Pages**
3. ในหัวข้อ **Build and deployment → Source** เลือก **Deploy from a branch**
4. Branch เลือก **main** (หรือ **master**) และโฟลเดอร์เลือก **/ (root)** แล้วกด **Save**
5. รอประมาณ 1-2 นาที แล้วรีเฟรชหน้า จะมีลิงก์ปรากฏขึ้นมา เช่น
   `https://ชื่อผู้ใช้.github.io/my-portfolio/`
6. เว็บจะเริ่มที่ `index.html` (ปกหน้า) โดยอัตโนมัติ — นี่คือลิงก์ที่ใช้แนบยื่นสมัครได้เลย

## ฟีเจอร์ในเว็บ
- เมนูแบบ Apple: กดไอคอน ☰ มุมขวาบน จะเห็นรายการทั้ง 12 หน้าแบบเต็มจอ กดเพื่อไปหน้านั้นได้ทันที
- ปุ่ม "หน้าก่อนหน้า / หน้าถัดไป" ด้านล่างทุกหน้า
- ใช้ปุ่มลูกศร ← → บนคีย์บอร์ดเพื่อเปลี่ยนหน้าได้เช่นกัน
- ข้อความและรูปค่อยๆ ปรากฏขึ้นเวลาเลื่อนดู (scroll reveal) แบบเดียวกับเว็บ Apple
- ปกหน้า/ปกหลังพื้นดำ-ตัวอักษรขาว ส่วนหน้าเนื้อหาพื้นขาว-ตัวอักษรดำ ให้ความรู้สึกเหมือนปกหนังสือ

## หมายเหตุ
- ถ้าต้องการแก้ไขเพิ่มเติมทีหลัง ให้แก้ไฟล์แล้วอัปโหลดซ้ำ (Upload files → Commit) เว็บจะอัปเดตอัตโนมัติ
- เว็บนี้รองรับมือถือ (responsive) และปิดแอนิเมชันอัตโนมัติถ้าเครื่องผู้ใช้ตั้งค่า "ลดการเคลื่อนไหว" ไว้
- แนะนำให้ทดสอบเปิดไฟล์ `index.html` ในเบราว์เซอร์ก่อน แล้วลองกดเมนู/ปุ่มเลื่อนหน้าดู เพื่อเช็คว่าทุกอย่างเชื่อมกันถูกต้องก่อนอัปโหลด
